# Terminal RPG: An AI-Powered Text Adventure

Terminal RPG is a free, browser-based text adventure that combines classic choose-your-own-adventure gameplay with modern AI.

Set in a retro terminal interface, the game dynamically generates stories, characters, encounters, puzzles, and combat scenarios based on your choices. Choose from 22 different themes, ranging from fantasy and mythology to cyberpunk, horror, science fiction, and post-apocalyptic settings.

The game is powered by AI models accessed through OpenRouter and uses a **Bring Your Own API Key (BYOK)** model.

## Getting Started

### 1. Get an OpenRouter API Key

Terminal RPG uses a **Bring Your Own API Key (BYOK)** model.

You provide your own OpenRouter API key, which is used by your browser to communicate with OpenRouter's API.

You can get an API key from [OpenRouter](https://openrouter.ai/?utm_source=chatgpt.com).

**Important:** Never share your API key with anyone or commit it to a public repository.

### 2. Start the Game

Open Terminal RPG and type:

```text
wake up
```

You will be prompted to:

1. Enter your OpenRouter API key.
2. Select an available AI model.
3. Choose an adventure theme.

### 3. Play

Follow the generated narrative and respond to story prompts by entering the number of your chosen option.

Monitor your character's:

* Health
* Inventory
* Current location

Your decisions shape the adventure.

## Privacy & API Keys

Terminal RPG follows a **BYOK (Bring Your Own API Key)** architecture.

* The project does not contain or provide a shared OpenRouter API key.
* You enter your own API key directly in the browser.
* The API key is stored locally in your browser for convenience.
* API requests are made directly from the browser to OpenRouter.
* Your API key is not intended to be transmitted to or stored by a Terminal RPG backend.

**Important:** Treat your API key as sensitive information. Do not share it publicly.
